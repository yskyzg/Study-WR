# 🍅 Study-WR · 番茄学习助手

> **一款为自学 / 考研 / 考证 / 备考而生的本地化 AI 学习管理工具**
>

把番茄钟、错题管理、计划排期、AI 复盘装进**一个 HTML 文件** —— **零依赖、零后端、零数据上传**。打开浏览器即用，数据永远留在你本地，AI 接口你自己配。

## 🚀 30 秒上手

```bash
# 方式 1：直接打开
双击 index.html

# 方式 2：本地服务器（推荐，避免某些浏览器限制）
npx serve .
# 或
python -m http.server 8080
```

打开后默认进入仪表盘，**先到「设置」页配置你的科目和 API Key，即可使用全部功能**。

## ✨ 功能详解

### 📊 1. 仪表盘

> 一眼看懂今天、本周的学习节奏

- 今日 / 本周学习时长统计与目标进度条
- **学习趋势折线图**：近 7 天 / 30 天可切换，支持按科目筛选
- **科目学习占比饼图**
- **错题分布柱状图** + **正确率对比柱状图**（按科目 / 题型筛选）
- **错题新增趋势图**
- **AI 智能提醒**：基于学习数据生成备考建议卡片，可展开收起

### 🍅 2. 番茄钟

> 专注 · 休息 · 自动归档

- **倒计时模式**（默认 25 分钟）和**正向计时模式**自由切换
- 自定义专注时长与休息时长
- 提前结束也能精确记录实际学习秒数
- 选择关联科目，学习记录自动归档到对应数据

### 📋 3. 计划管理

> 短期 + 长期，全周期规划

- 新建 / 编辑 / 删除学习计划，**截止日期 + 优先级**
- **长期计划**：设置阶段目标与科目排期，临近到期自动提醒
- 长期计划卡片支持进度条可视化

### 📚 4. 错题管理

> 拍照 · 上传 · AI 解答 · 导出

- 按科目 / 题型录入错题，**支持图片上传**
- 自动统计总题数 / 错题数 / 正确率
- 按科目 / 题型筛选
- **批量导出 ZIP** / 单错题导出多页 PDF（含图片）
- 🤖 **AI 对话式解答**：每道错题可发起 AI 对话，生成解析与改进建议

### 📝 5. 每日 / 每周复盘

> 结构化模板 + AI 报告

- 三段式复盘：**收获 / 不足 / 改进**
- 🤖 **AI 一键生成复盘报告**：每日 / 每周模式可切换
- 历史复盘记录可查看、可批量导出 ZIP
- 多套提示词（**前置提示词**）个性化 AI 输出方向

### ⚙️ 6. 设置

> 一切按你习惯来

- **科目管理**：名称、颜色、题型配置
- **目标管理**：每日 / 每周学习目标分钟数
- **AI 接口配置**：支持 OpenAI / DeepSeek 等兼容接口
  - 🔄 **多套 API 预设**保存与切换（适合有多个模型账号的用户）
  - 模型选择、连通性测试、自定义 `baseUrl`
- **数据导入 / 导出**：JSON 格式一键备份与还原

## 🛠 技术栈

| 模块         | 实现                                                                  |
| ------------ | --------------------------------------------------------------------- |
| **前端架构** | 单文件 HTML + CSS + 原生 JavaScript（无构建步骤）                     |
| **图表库**   | [Chart.js v4.5.1](https://www.chartjs.org/)（内联，无 CDN 依赖）      |
| **数据存储** | 浏览器 `localStorage`（key: `civilServiceExamReviewPomodoroStateV1`） |
| **AI 接口**  | OpenAI 兼容 REST API（用户自配 Key）                                  |
| **部署**     | 任意静态文件服务即可                                                  |

### 为什么选单文件架构？

- 🎯 **零部署**：下载即用，邮件附件也能发
- 🔒 **隐私天然**：不存在"服务器"概念，数据不可能外流
- ⚡ **极轻量**：打开速度比任何 SPA 都快

---

## 🔐 数据与隐私

> **Study-WR 永远不会上传你的任何数据。**

- ✅ **本地存储**：所有数据（学习记录、错题、复盘、AI 对话历史）保存在浏览器 `localStorage`
- ✅ **数据备份**：「设置」可一键导出 JSON，换设备时导入还原
- ✅ **AI 请求直连**：AI 请求**直接从浏览器发到你配置的第三方 API**，不经过任何中转服务器
- ✅ **无埋点、无追踪**：项目无任何分析脚本
- ⚠️ **API Key 本地保存**：仅适合个人本地使用，请勿在公共设备保存
