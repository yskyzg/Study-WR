# 番茄学习助手

面向自学、考研、考证、备考等各类学习场景的一体化学习管理工具，集番茄钟、错题管理、学习复盘于一体。单文件应用，无需安装，打开即用。

## 功能模块

### 仪表盘
- 今日 / 本周学习时长统计及目标进度
- 学习趋势折线图（近 7 天 / 30 天，可按科目筛选）
- 科目学习占比饼图
- 错题分布、正确率对比柱状图（可按科目 / 题型筛选）
- 错题新增趋势图
- AI 智能提醒：基于学习数据生成备考建议，以可展开卡片形式展示

### 番茄钟
- 倒计时与正向计时两种模式
- 可自定义专注时长与休息时长
- 提前结束并记录实际学习时长（精确到秒）
- 关联科目，学习记录自动归档

### 计划管理
- 新建、编辑、删除学习计划，支持截止日期与优先级
- 长期计划：设置阶段目标与科目排期，临近到期自动提醒

### 错题管理
- 按科目 / 题型录入错题，支持上传图片
- 记录总题数与错题数，自动计算正确率
- 按科目 / 题型筛选，支持批量导出（ZIP 打包）
- AI 解答：对话式 AI 分析错题，生成解析与改进建议
- 导出为 PDF（支持多页，含图片）

### 每日 / 每周复盘
- 结构化复盘模板（收获、不足、改进）
- AI 一键生成复盘报告（支持每日 / 每周模式）
- 历史复盘记录查看，支持批量导出为 ZIP

### 设置
- 科目管理（名称、颜色、题型配置）
- 每日 / 每周学习目标设置
- AI 接口配置（支持 OpenAI / DeepSeek 等兼容接口）
- 多套 API 预设保存与切换
- 前置提示词（个性化 AI 输出方向）
- 数据导入 / 导出（JSON）

## 快速开始

无需安装任何依赖，直接用浏览器打开：

```
index.html
```

或通过本地静态服务器访问：

```bash
npx serve .
# 或
python -m http.server 8080
```

## 技术栈

| 项目 | 说明 |
|------|------|
| 实现方式 | 单文件 HTML + CSS + JavaScript |
| 图表 | Chart.js（内联） |
| 数据存储 | 浏览器 `localStorage` |
| AI 接口 | OpenAI 兼容 REST API（用户自行配置） |
| 构建依赖 | 无 |

## 数据说明

所有数据存储在浏览器本地，`localStorage` 键名：

```
civilServiceExamReviewPomodoroStateV1
```

- 数据仅存在于当前浏览器，清除浏览器数据会导致丢失
- 可在「设置」页导出 JSON 备份，换设备时导入还原
- AI 接口的 API Key 同样保存在 `localStorage`，仅适合个人本地使用，请勿在公共设备上保存

## 隐私说明

- 无服务器、无埋点、无任何数据上传
- AI 功能需用户自行配置第三方接口，请求直接从浏览器发出
