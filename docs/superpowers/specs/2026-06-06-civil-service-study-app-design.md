# 公务员考试备考智能复盘与番茄钟工具设计

## 背景与目标

构建一个纯 HTML/CSS/JavaScript 单文件应用，作为公务员考试备考的本地化学习管理工具。应用直接在浏览器运行，不需要后端服务或构建步骤。所有业务数据保存在 `localStorage`，适合个人长期使用。

## 范围

本次实现包含以下模块：

1. 仪表盘：展示今日学习总时长、完成番茄数、学习时间占比、趋势图、错题分布、AI 提醒。
2. 番茄钟：支持自定义专注/休息时长、开始/暂停/重置、环形进度条、结束音效、按科目记录学习时长。
3. 学习计划：新增、编辑、删除每日/每周任务，任务包含名称、科目、预计番茄数、截止日期、完成状态，并按未完成/已完成分组。
4. 错题记录：按科目记录题目摘要、错误原因、正确答案、知识点标签、日期，支持筛选、编辑、删除。
5. 时间可视化：使用 Chart.js CDN 实现近 7/30 天学习趋势折线图、科目学习时间饼图、错题数量柱状图。
6. 复盘反思：每日/每周复盘模板，自动附带当日学习时长和错题数量摘要，可按日期查看历史复盘。
7. 科目管理：预置公务员考试常见科目，支持颜色标签、增删改，所有下拉列表同步。
8. AI 辅助：设置 OpenAI-compatible API Key、Base URL、模型名；支持 AI 复盘和智能提醒，显示加载与错误状态。

## 非目标

- 不引入后端、数据库、登录系统或云同步。
- 不做复杂权限、安全加密或多用户协作。
- 不拆分文件或引入构建工具。
- 不承诺 API Key 的浏览器级强安全性；仅按用户要求存储在 `localStorage`。

## 技术方案

采用一个 `index.html` 文件，包含：

- HTML：侧边栏、主内容区域、各模块表单与卡片。
- CSS：冷色渐变背景、玻璃质感卡片、响应式布局、按钮与表单样式。
- JavaScript：应用状态、localStorage 持久化、视图渲染、表单处理、番茄钟、图表刷新、AI 调用。
- CDN：引入 Chart.js 最新版。

代码按对象和函数分区组织，避免外部依赖和构建复杂度。

## 数据模型

`localStorage` 使用单个主键保存应用状态对象：

- `subjects`: `{ id, name, color }[]`
- `plans`: `{ id, title, subjectId, pomodoros, dueDate, scope, completed, createdAt }[]`
- `mistakes`: `{ id, subjectId, summary, reason, answer, tags, date }[]`
- `sessions`: `{ id, subjectId, minutes, type, startedAt, endedAt }[]`
- `reviews`: `{ id, date, period, completed, problems, improvements, tomorrow, aiAdvice }[]`
- `settings`: `{ focusMinutes, breakMinutes, apiKey, baseUrl, model }`

初始化时如果没有存储数据，则写入预置科目和少量示例数据，便于图表初次展示。

## 主要交互

### 番茄钟

用户必须先选择科目才能开始专注计时。计时状态包括 idle、running、paused。专注计时结束后播放提示音，将专注分钟数记录到 `sessions`，再切换到休息模式。休息结束后仅提醒，不记录学习时长。

### 计划

计划任务通过表单新增。编辑时复用表单或行内填充；删除前使用 `confirm()`。列表展示当日/全部任务，并按未完成和已完成分组。

### 错题

错题支持按科目筛选。新增/编辑后实时更新柱状图与复盘摘要。删除前使用 `confirm()`。

### 图表

图表数据从当前状态聚合，不单独存储统计结果。切换 7 天/30 天范围时重新计算趋势数据。饼图和柱状图使用科目颜色。

### 复盘

复盘表单使用固定模板字段：今日完成情况、困难与不足、改进措施、明日重点。页面自动展示所选日期的学习时长与错题数量摘要。保存后可按日期查看。

### AI 辅助

设置页保存 API Key、Base URL、模型名。AI 复盘会收集今日学习时长、科目占比、错题记录、复盘笔记，构造结构化 prompt，请求 OpenAI-compatible `/chat/completions` 接口。智能提醒会根据当日计划完成度和学习数据生成短提醒。调用期间显示加载状态，失败时展示错误消息。

## 错误处理

- 缺少必填字段时使用页面提示或 `alert()`。
- 删除操作使用 `confirm()`。
- API 配置缺失、网络失败、返回格式异常时显示可读错误。
- Chart.js 未加载时不阻塞核心表单和数据功能。

## 验收标准

1. 打开生成的 HTML 文件即可使用，无需构建。
2. 关闭并重新打开页面后，科目、计划、错题、番茄记录、复盘和设置仍保留。
3. 番茄钟必须选择科目才能开始；专注结束后自动记录该科目学习时长。
4. 学习计划、错题、复盘、科目均支持基本增删改或保存操作。
5. 仪表盘图表能根据本地数据更新，并支持 7/30 天趋势切换。
6. AI API 配置完整时可发起请求；加载和错误状态清晰可见。
7. 整体视觉为极简冷色渐变与半透明卡片风格，适合长时间学习。
